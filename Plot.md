# Graph Plotting and 3D Visualization Library

A comprehensive collection of data visualization scripts and programs, ranging from standard 2D statistical plots to interactive 3D surface . 
This repository serves as a personal portfolio and reference guide for implementing high-quality scientific and mathematical plots.

## Features

* **2D Plotting:** Standard Trigonometric graphs,some experimental and sci fiction.
* **3D Visualization:** Surface plots, wireframes, 3D scatter plots, and contour maps of Wormhole.
* **Interactivity:** Support for zoom, pan, and hover metrics (using libraries like Matplot lib).
* **Customization:** Clean color palettes, custom grid layouts, and publication-ready export formats.

## Prerequisites

Before running the programs, ensure you have the following programming language and libraries installed:

* Python 3.8 or higher
* Matplotlib
* NumPy
* Scipy
  

## Installation

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```

2. Navigate into the project directory:
   ```bash
   My Plot programms 
   ```

3. Install the required dependencies:
   ```bash
   pip install -r Matplotlib,Scipy and Numpy
   ```

## Usage

Each script is organized by dimension and complexity. Run any script directly from your terminal.
